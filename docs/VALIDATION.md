## 브라우저

로컬 Chromium에서 확인했습니다.

- 320 / 390 / 768 / 1280px 너비에서 보스 9마리 2열 표시, 가로 스크롤 없음.
- 알림 토글·침공 선택·보스 순서·알림 시점이 새로고침 후 유지됨.
- 연결되지 않은 상태의 테스트 버튼 비활성, 설치 안내 표시.
- 서비스 워커 등록과 오프라인 재실행. 마지막 관측 9마리 표시와 ‘오프라인 자료’ 안내.
- 작은 화면의 이름·남은 시간·예정 시각이 잘리지 않음.
- 카드 간소화 후 320 / 390 / 768 / 1280px에서 이름과 우측 상단 알림 버튼이 겹치지 않고, 11시간 55분 같은 긴 남은 시간도 잘리지 않음을 확인했습니다. 모바일 카드 높이는 113~116px이며 알림 터치 영역은 44×44px입니다.
- 카드의 날짜·세부 지역명 제거, 시·분 예정 시각과 자료 부족 표시 유지, 알림 선택 후 버튼·테두리 강조가 카운트다운 갱신과 새로고침 후에도 유지됨을 확인했습니다.
- 카드 개편은 공개 웹에서도 확인했습니다. 개편 후 에뮬레이터 연결이 종료되어 기존 APK에서의 추가 재확인은 하지 못했습니다.
- 정렬 메뉴 4종과 ‘내 순서’ 전환, 자동 정렬 중 기존 사용자 순서 보존, 새로고침 복원, 기존 저장 순서 이관을 확인했습니다.
- Chromium 모바일 터치 입력에서 드래그 이동·카운트다운 중 미리보기 유지·화면 가장자리 자동 스크롤·터치 취소 복구를 확인했습니다. 마우스 드래그·방향키 이동·Escape 취소도 확인했습니다.
- 정렬 추가 후 320 / 390 / 768 / 1280px에서 일반·편집 모드 모두 2열 유지와 가로 넘침 없음을 확인했습니다. 일반 모드 모바일 카드 높이는 113~116px을 유지합니다.
- 브라우저 시각을 고정해 예정 시각 경과 시 다음 회차에 맞춰 시간순 카드 배치가 자동 갱신되는 것을 확인했습니다. 이번 정렬 기능의 Android/iPhone 실기기 터치는 별도 확인이 필요합니다.
- 공개 HTTPS 주소에서도 정렬 메뉴·레벨 정렬·모바일 터치 드래그·새로고침 후 사용자 순서 유지와 새 캐시 버전을 확인했습니다.

공개 사이트의 데스크톱 Chrome에서는 실제 푸시 서비스 수신을 확인했습니다. Android/iPhone 잠금 화면 수신·기기 소리·진동은 별도 실기기 확인이 필요합니다. 데스크톱 수신 성공을 휴대폰 실수신 성공으로 간주하지 않습니다.
