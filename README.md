# 제우스 보스 타이머

Android·iPhone 공통 PWA입니다. 웹 수정 후 배포하면 APK 재설치 없이 반영됩니다. 공통 보스 시간은 운영자가 게시하고, 이용자는 알림과 순서만 선택합니다.

**사용 주소: https://zeus-boss-timer.zeus-boss-timer.workers.dev**

## 사용

1. 배포 주소를 엽니다.
2. iPhone: Safari 공유 → 홈 화면에 추가 → 추가된 앱을 엽니다. iOS 16.4 이상이 필요합니다.
3. Android: Chrome 메뉴 → 앱 설치 또는 홈 화면에 추가.
4. 설정에서 **알림 연결**을 누르고 권한을 허용합니다.
5. 보스별 알림과 00시·12시·18시 침공 알림을 선택합니다. 기본은 모두 꺼짐입니다.
6. **10초 뒤 테스트**를 누르고 화면을 잠가 확인합니다. 소리·진동은 기기 설정을 따릅니다.

일반 보스는 10분·5분·1분 전·예정 시각을 선택하며 기본은 5분 전과 예정 시각입니다. 침공은 한국시간 정각 알림만 보냅니다. 기기 전원이 완전히 꺼진 동안 수신할 수는 없습니다.

## 로컬 실행

Node.js 22 이상 안정 버전을 사용합니다.

```powershell
npm ci
npm run keys
npm run db:local
npm run dev
```

http://127.0.0.1:8787 에서 확인합니다. `npm run keys`는 비밀키가 들어 있는 `.dev.vars`를 만들며 기존 파일을 덮어쓰지 않습니다. 이 파일은 Git에 올리지 않습니다.

```powershell
npm test
npm run check
```

실제 로컬 D1에서 예약 저장·해제·중복 방지·만료·오류 재시도와 암호화 푸시 요청을 검사합니다. 브라우저 검사 결과와 실기기 확인 여부는 [검증 기록](docs/VALIDATION.md)에 있습니다.

## 공통 시간 수정

- 원본 기록: [BOSS-OBSERVATIONS.md](BOSS-OBSERVATIONS.md), `docs/observations/`의 원본 이미지.
- 실제 앱 데이터: `public/data/catalog.json`.
- 촬영 시각은 한국시간으로 기록합니다. 촬영 초를 모르면 `:00`은 계산용 대표값이며 정확한 초로 간주하지 않습니다.
- 같은 회차 보정은 기존 `cycleId`를 유지한 채 `observations` 마지막에 추가합니다.
- 새 회차는 새로운 `cycleId`를 사용합니다. **바로 이전 회차임이 확인된 경우만** `consecutiveFrom`에 이전 ID를 넣습니다. 중간 회차를 놓쳤으면 생략합니다.
- `revision`, `capturedAt`, `source`도 갱신하고 `npm run deploy`합니다.
- 보스 ID는 유지합니다. 이름·레벨·지역·리스폰·초상화 위치를 수정할 수 있습니다.

화면은 1분마다 또는 앱으로 돌아올 때 자료를 다시 읽습니다. 화면 코드가 바뀌면 서비스 워커의 새 버전을 안내합니다. 오프라인에서는 마지막 자료임을 표시합니다.

최근 최대 10개의 유효한 연속 회차 간격 중앙값으로 다음 **한 회차만** 추정합니다. 표본이 없으면 사용자 제공 리스폰을 쓰고 보정자료 부족을 표시합니다. 다음 추정까지 지나면 새 관측 대기 상태가 됩니다. 추정을 관측으로 학습하지 않습니다.

## 무료 배포

Cloudflare Workers 정적 파일 + D1 + 분 단위 Cron + Queues를 사용합니다. 별도 서버 임대는 없습니다. 설치와 운영 명령은 [배포 안내](docs/DEPLOYMENT.md)를 따릅니다.

웹 푸시 주소·암호화 키·선택 설정·발송 상태만 D1에 저장합니다. 로그인과 개인 보스 기록은 없습니다. 알림 연결을 해제하면 기기 구독과 예약을 삭제합니다. 비공개 토큰은 기기에만 보관하고 서버에는 해시로 저장합니다.

Cron과 푸시 전달은 지연될 수 있으며 정확한 초 단위 도착을 보장하지 않습니다. 2분 이상 늦거나 사전 알림 시점이 출현을 지난 경우 폐기합니다. 푸시 서비스가 수신한 직후 저장이 실패하는 드문 경우의 중복 가능성은 시스템 알림 태그로 줄입니다.

Safari의 구독 유지 규칙에 따라 기기까지 수신한 푸시는 항상 표시합니다. 처리 지연으로 만료된 메시지는 지난 카운트다운 대신 ‘지연된 알림’ 안내로 표시합니다.

## 파일 구성

- `public/`: 웹 화면, PWA, 공통 자료, 시간 계산.
- `src/worker.js`: 구독 API, 예약과 암호화 푸시 발송.
- `migrations/`: D1 스키마.
- `test/`: 계산과 실제 로컬 D1 검사.
- [ROADMAP.md](ROADMAP.md): 확정 요구사항.
- [기존 Android 문서](docs/LEGACY-ANDROID.md): 초기 사양과 기록 보존용. 현재 PWA 사용법과 다릅니다.
