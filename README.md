# 제우스 보스 타이머

Android·iPhone 공통 PWA입니다. 웹 수정 후 배포하면 APK 재설치 없이 반영됩니다. 공통 보스 시간은 운영자가 게시하고, 이용자는 알림과 순서만 선택합니다.

Android Studio 에뮬레이터에서 설치형으로 확인할 때는 [테스트 APK 프로젝트](android/README.md)를 사용합니다. 같은 웹을 여는 TWA이며 기존 PWA도 그대로 지원합니다.

**사용 주소: https://zeus-boss-timer.zeus-boss-timer.workers.dev**

## 사용

1. 배포 주소를 엽니다.
2. iPhone: Safari 공유 → 홈 화면에 추가 → 추가된 앱을 엽니다. iOS 16.4 이상이 필요합니다.
3. Android: Chrome 메뉴 → 앱 설치 또는 홈 화면에 추가.
4. 톱니바퀴 **환경설정**에서 **푸시 알림 허용 · 연결**을 누르고 권한을 허용합니다.
5. 보스별 알림과 00시·12시·18시 침공 알림, 필드 보스 알림 시점을 선택한 뒤 **설정 저장**을 누릅니다. 기본은 보스 미선택·5분 전입니다.
6. **10초 뒤 테스트**를 누르고 화면을 잠가 확인합니다. 소리·진동은 기기 설정을 따릅니다.

일반 보스는 **1분·3분·5분 전** 중 여러 시점을 선택할 수 있습니다. 침공은 한국시간 정각 알림만 보냅니다. 기기 전원이 완전히 꺼진 동안 수신할 수는 없습니다.

환경설정의 전체 알림 스위치를 끄고 저장하면 선택을 보존한 채 필드·침공·테스트 알림을 중지합니다. 다시 켜고 저장하면 선택한 알림을 재개합니다. 변경 후 X·닫기·Escape로 나가면 미저장 변경을 버릴지 확인합니다. 저장 실패 시 편집값을 유지하며 다시 저장할 수 있습니다.

푸시 연결·권한 확인·테스트·연결 해제는 즉시 실행됩니다. **기기 알림 설정 안내**는 휴대폰별 소리·진동 설정 경로를 보여 주며 시스템 설정은 사용자가 직접 변경합니다. 목록의 보스·침공 바로가기 토글은 즉시 저장됩니다.

## 로컬 실행

Node.js 22 이상 안정 버전을 사용합니다.

```powershell
npm ci
npm run keys
npm run db:local
npm run dev
```

http://127.0.0.1:8787 에서 확인합니다. `npm run keys`는 비밀키가 들어 있는 `.dev.vars`를 만들며 기존 파일을 덮어쓰지 않습니다. 이 파일은 Git에 올리지 않습니다.

```powershell
npm test
npm run check
```

실제 로컬 D1에서 예약 저장·해제·중복 방지·만료·오류 재시도와 암호화 푸시 요청을 검사합니다. 브라우저 검사 결과와 실기기 확인 여부는 [검증 기록](docs/VALIDATION.md)에 있습니다.

## 공통 시간 수정

- 원본 기록: [BOSS-OBSERVATIONS.md](BOSS-OBSERVATIONS.md), `docs/observations/`의 원본 이미지.
- 실제 앱 데이터: `public/data/catalog.json`.
- 촬영 시각은 한국시간으로 기록합니다. 촬영 초를 모르면 `:00`은 계산용 대표값이며 정확한 초로 간주하지 않습니다.
- 같은 회차 보정은 기존 `cycleId`를 유지한 채 `observations` 마지막에 추가합니다.
- 새 회차는 새로운 `cycleId`를 사용합니다. **바로 이전 회차임이 확인된 경우만** `consecutiveFrom`에 이전 ID를 넣습니다. 중간 회차를 놓쳤으면 생략합니다.
- `revision`, `capturedAt`, `source`도 갱신하고 `npm run deploy`합니다.
- 보스 ID는 유지합니다. 이름·레벨·지역·리스폰·초상화 위치를 수정할 수 있습니다.

관리자 버튼에서 비밀번호로 인증한 뒤 보스를 누르면 남은 시간·분을 수정합니다. 저장 시점부터 정수 분을 적용하며 모든 이용자가 같은 값을 읽습니다. 0시간 0분은 다음 리스폰을 시작합니다. 비밀번호는 `.dev.vars`의 `ADMIN_PASSWORD="직접 정한 값"`으로 설정하고 `node scripts/upload-secrets.js`로 비공개 등록합니다. 인증은 8시간 유지되며 관리자 종료 버튼으로 해제합니다.

열린 화면은 15초마다 또는 앱으로 돌아올 때 공통 자료를 다시 읽습니다. 남은 시간은 기기 시각으로 매초 재계산하고 시간·분만 표시합니다. 화면 코드가 바뀌면 서비스 워커의 새 버전을 안내합니다. 오프라인에서는 마지막 자료임을 표시합니다.

관리자 버튼을 다시 누르면 수정 이력을 볼 수 있습니다. 보스별 최신 적용 수정의 ‘이 수정 되돌리기’를 누르면 이전 기준으로 복원하며 모든 앱에 공유됩니다. 기록은 삭제하지 않고 취소 이력을 추가하며 취소된 값은 보정 계산에서 제외합니다.

알람·전체 알림·침공 선택은 기기별 인증 토큰으로 분리되며 다른 이용자에게 전파되지 않습니다. 정렬도 기기 안에만 저장합니다. 연결 장애 시 변경은 기기에 보관해 재전송하며, 서버 적용 확인 전에는 기존 알림이 도착할 수 있다는 상태를 표시합니다. 같은 기기의 같은 브라우저 저장소를 사용하는 TWA와 웹 화면은 설정을 공유합니다.

카드에는 관측 기준·자료 부족 같은 상태 문구 없이 남은 시간과 예정 시각을 표시합니다. 예정 시각은 모두 근사값이며, 이미지를 계속 보내지 않아도 반복 계산합니다. 새 이미지나 관리자 수정값을 받으면 기존 이력에 누적해 오차를 보정합니다.

출현 간격은 **리스폰 + 처치시간**입니다. 기본 처치시간은 테살리아 15초·자하브 30초이며, 예정 시각이 지나면 처치를 전제로 다음 회차를 계산합니다. 이미지 관측과 관리자 수정 이력을 함께 보존·사용하며 같은 회차 수정은 중복 표본으로 세지 않습니다. 최근 10개 유효 간격의 정밀도 가중 중앙값을 기본값과 섞어 보스별로 점진 보정합니다. 분 입력·촬영 초 미상은 낮은 가중치로 처리합니다. 자동 반복 추정은 학습하지 않습니다.

## 무료 배포

Cloudflare Workers 정적 파일 + D1 + 분 단위 Cron + Queues를 사용합니다. 별도 서버 임대는 없습니다. 설치와 운영 명령은 [배포 안내](docs/DEPLOYMENT.md)를 따릅니다.

웹 푸시 주소·암호화 키·선택 설정·발송 상태와 관리자 공통 수정 이력·인증 세션을 D1에 저장합니다. 개인 보스 기록은 없습니다. 알림 연결을 해제하면 기기 구독과 예약을 삭제합니다. 인증 토큰은 서버에 해시로 저장합니다.

Cron과 푸시 전달은 지연될 수 있으며 정확한 초 단위 도착을 보장하지 않습니다. 2분 이상 늦거나 사전 알림 시점이 출현을 지난 경우 폐기합니다. 푸시 서비스가 수신한 직후 저장이 실패하는 드문 경우의 중복 가능성은 시스템 알림 태그로 줄입니다.

Safari의 구독 유지 규칙에 따라 기기까지 수신한 푸시는 항상 표시합니다. 처리 지연으로 만료된 메시지는 지난 카운트다운 대신 ‘지연된 알림’ 안내로 표시합니다.

## 파일 구성

- `public/`: 웹 화면, PWA, 공통 자료, 시간 계산.
- `src/worker.js`: 구독 API, 예약과 암호화 푸시 발송.
- `migrations/`: D1 스키마.
- `test/`: 계산과 실제 로컬 D1 검사.
- [ROADMAP.md](ROADMAP.md): 확정 요구사항.
- [기존 Android 문서](docs/LEGACY-ANDROID.md): 초기 사양과 기록 보존용. 현재 PWA 사용법과 다릅니다.
